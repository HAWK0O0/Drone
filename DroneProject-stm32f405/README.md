# STM32F405 Advanced Flight Controller Prototype

This folder contains one of the most advanced stages of the repository: a custom flight-controller project built around STM32F405.

## Purpose

This project is intended to become a more capable and professional all-in-one flight-controller platform for future drone development.

## Main goals

- support more advanced embedded flight stacks
- prepare for Betaflight / INAV-class capabilities
- integrate camera, GPS, and Wi-Fi connectivity
- overcome earlier limits in memory size and processing speed
- provide a stronger platform for future autonomous and robotics-oriented features

## Status

The board design is approximately 90% complete and is currently paused before final routing and production preparation.

## Project type

Advanced custom PCB flight-controller development.
