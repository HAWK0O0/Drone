# Hardware Components Reference

This folder contains reference material for the main hardware components used across the drone projects in this repository.

It is intentionally kept separate from the main project folders so that each project can remain independent while still sharing a common hardware reference base.

## Purpose

This directory documents the physical parts, modules, and hardware notes used during development, testing, troubleshooting, and prototype planning.

It includes references for:
- frame components,
- motors and propellers,
- ESCs,
- sensors,
- radio systems,
- batteries,
- ESP32 modules,
- and STM32-related notes.

## Main Component Groups

- **Frame:** DJI F450 body
- **Motors:** DJI 2212 920KV
- **Propellers:** 1045 drone propellers
- **ESCs:** 30A and 40A ESC variants
- **Sensors:** MPU6050, BNO055, Hall effect sensor modules
- **Navigation:** GPS NEO-7M
- **Control / Communication:** HT-8A transmitter and receiver, ESP-based modules
- **Processing Platforms:** ESP32-S3 and STM32F405-related references
- **Power:** 3S 4200mAh LiPo battery

## Notes

Some files in this folder are technical notes, wiring references, component documentation, and engineering records collected during the project.

This folder supports the drone projects but is not itself a standalone flight-controller project.
