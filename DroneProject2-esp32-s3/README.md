# ESP32-S3 Flight Controller Prototype V2

This folder contains a major ESP32-S3-based development stage of the drone project.

## Purpose

This project focuses on improving flight control, stabilization, telemetry, and software flexibility using ESP32-S3.

## Main work

- embedded flight-controller development
- UART / USB conflict handling
- SBUS integration
- MPU-6050 sensor integration
- PID tuning and stabilization work
- telemetry-related development
- AI-assisted software support

## Special feature

This project also includes work related to browser-based tuning and engineering support documentation.

## Status

Active prototype and major development stage.
